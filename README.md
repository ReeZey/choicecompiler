# choicervoicer compiler/exporter  
used to create .mp4 files of raw ChoicerVoicer files you get when you press (Save Dub)  


to easily share on discord etc

# setup
### make sure ffmpeg is installed and is available in path
otherwise install it before continuing

## windows
the path will be correct and it will resolve the path automaticaly, if for some reason the game folder is in a different path it can be set in `config.toml`

## linux
the path will be needed to be set in `config.toml`, this is cause its on different places depending on distro or other setup like running through Bottles/Wine

# usage
1. run the executeable
2. select the correct "dub pack" from the list by corresponding number
3. select the date, which recording it will use 
4. set output name, without .mp4

5. let ffmpeg do its thing
6. ???
7. profit
